# Cars Dealership

**Repository Name:** `xrwvm-fullstack_developer_capstone`

## Project Description

The Cars Dealership project is a full-stack web application built using Django and React. It provides dealership information and supports features such as user authentication, dealership browsing, and customer reviews.

- Python
- Django
- React
- JavaScript
- HTML and CSS
- Bootstrap
